# 서정 출장서류

서정대학교 입학본부 출장 승인·결의 서류 작성 웹앱 (공개 배포본).

- 사이트: https://blowinds33-stack.github.io/seojeong-trip-site/
- 출장 기록과 올린 파일은 사용하는 **브라우저 안에만** 저장됩니다. 이 저장소와 사이트에는 업무 자료가 없습니다.
- 예산 코드표는 사이트에 들어 있지 않습니다. 처음 쓸 때 설정에서 기준표 엑셀을 올립니다.
- AI 작성은 설정에 넣은 본인 Anthropic API 키로 실행됩니다(사용량은 키 소유 계정에서 차감).
- 출장 외 업무(홍보물·구매·회의·특강 등 승인에서 결의까지): https://blowinds33-stack.github.io/seojeong-trip-site/work.html — 출장 서류에서 넣은 API 키와 올린 예산 코드표를 같은 브라우저에서 함께 씁니다.
- 원본 코드는 비공개 저장소에서 빌드해 `index.html`(출장 서류)과 `work.html`(출장 외 업무)로 올립니다. 이 저장소의 파일을 직접 고치지 마세요.
